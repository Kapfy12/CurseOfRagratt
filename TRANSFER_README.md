# Замок Раргратт — перенос на GitHub

Игра: v0.2.31. Это упаковка существующей версии, не новое игровое обновление.

## Запуск
Откройте index.html в браузере. Основные игровые ассеты встроены в HTML.
Либо: `python3 -m http.server 8000` и откройте http://localhost:8000.

## Загрузка в новый пустой репозиторий
Распакуйте архив, откройте терминал в его папке:

```bash
git init
git add .
git commit -m "Import game v0.2.31"
git branch -M main
git remote add origin https://github.com/YOUR_LOGIN/YOUR_REPOSITORY.git
git push -u origin main
```
Замените YOUR_LOGIN и YOUR_REPOSITORY своими значениями.
Авторизуйтесь через GitHub CLI или менеджер учётных данных Git. Не передавайте токены в чат.

## Состав компактной копии
- index.html — автономная игра со встроенными ассетами.
- heroes/sprites — рабочие PNG, риги, сборщики анимаций, заметки.
- heroes/assets — выбранные актуальные исходники крысы, арбалетчика, зомби и останков.
- tools — проверки, журнал версий и утилиты.
- VERSIONING.md — правило обновления номера версии.
- TRANSFER_MANIFEST.json — контрольные SHA-256 всех включённых файлов и перечень исключённых.

Это НЕ полный архив всех исторических материалов. Не включены старые макеты страниц,
исходники деревни/магазинов/героев и прочие тяжёлые материалы вне текущей работы со
спрайтами. Для запуска игры они не требуются: изображения уже встроены в HTML.
Старые скрипты могут ссылаться на исключённые исходники; их полная пересборка из этого
компактного архива не гарантируется. Не запускайте build_game_assets.py поверх игры:
это может перезаписать ручные изменения.

## Анимации и восстановление
Анимации хранятся как PNG-спрайт-листы, не GIF. GIF-превью ранее удалены намеренно.
`python3 tools/recover_embedded_sprites.py` извлечёт явно зарегистрированные PNG из
index.html в recovered_assets. Основная копия рабочих файлов — heroes/sprites.
Для Python-сборщиков обычно нужны pillow, numpy, scipy; для браузерных тестов playwright
и установленный браузер. См. requirements.txt.

## Дальнейшие правки
Сохраняйте рабочую версию в Git после каждой завершённой правки. Для работы в чате
передавайте актуальные нужные файлы или компактный ZIP. В этой среде прямой коннектор
GitHub недоступен: изменения можно вернуть файлами/патчем и загрузить в Git локально.
